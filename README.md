# LK-47.web

A WebArena agent with no language model and no learned weights. A grammar reads each task's intent into one of the 190 intent templates and its slot values, and a hand-written plan of site skills carries it out through the original harness's `playwright` action set.

One run over all 812 tasks of the original harness passed 631 (77.71%). The 84 tasks that need the harness's GPT-4 judge count as failures. The plans were written against the test intents, so this is an expert system for these templates, not a general agent. Trajectories, per-task results and setup notes are in the [run release](https://github.com/LK-maker-007/LK-47.web/releases/tag/run-2026-10-09).

## Setup

Python 3.10, with the harness at commit dce04686 in `third_party/webarena`:

    git clone https://github.com/web-arena-x/webarena third_party/webarena
    git -C third_party/webarena checkout dce04686a56253aefba7b18a4fa0937cf1dc987b
    uv venv --python 3.10 .venv
    uv pip install --python .venv/bin/python -r third_party/webarena/requirements.txt -e third_party/webarena lxml cssselect pytest
    .venv/bin/playwright install chromium

Host the WebArena sites, then generate the task configs in the harness with its `scripts/generate_test_data.py`. The runner reads the site addresses from `SHOPPING`, `SHOPPING_ADMIN`, `REDDIT`, `GITLAB`, `MAP`, `WIKIPEDIA` and `HOMEPAGE`, with localhost defaults.

## Run and score

    .venv/bin/python -m lk47.runner.live --tasks 0 1 2 --result-dir results/demo
    .venv/bin/python scripts/score.py results/demo

`.venv/bin/python -m pytest` runs the unit tests against saved pages, without a browser.

`lk47/intents/templates_data.py` is generated by `scripts/gen_templates.py` from WebArena's `test.raw.json`, which is under the Apache License 2.0.
